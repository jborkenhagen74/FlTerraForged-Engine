# Upstream provenance

No TerraForged, ReTerraForged, FreeTerraForged or AronaLayers source code is
included in `0.1.0-SNAPSHOT`.

The projects below are research/reference sources for later, explicitly traced
migration commits:

- TerraForged / TerraForged Engine — original algorithms and behavior.
- ReTerraForged 1.20.1 — modernized terrain/noise/worldgen implementation.
- FreeTerraForged 1.21.1_V0.0.6005 — later fixes and NeoForge-era integration.
- AronaLayers-gen — reference for fractional surfaces and layer placement; this
  functionality belongs to FlTerraForged's surface layer, not this engine.
- AronaLayers-extras — reference for optional layer runtime behavior; not engine
  functionality.

For every later imported or substantially derived implementation, retain the
applicable license/copyright notices and document the source path/commit here.
